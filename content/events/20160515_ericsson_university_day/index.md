abstract: This poster outlines a collaborative research project by Ericsson and ELTE University, focused on analyzing MySQL NDB cluster communication. In this project, we developed methods for granular analysis of cluster response times, involving an in-depth examination of the communication protocol. Despite the absence of comprehensive protocol documentation, insights were drawn from MySQL Cluster source code and real CUDB system packet traces. Examination of the response times of some key queries opens the possibility for dynamic load balancing.
