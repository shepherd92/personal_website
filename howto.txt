Start
    Academic CV Template
        download from https://github.com/HugoBlox/theme-academic-cv
    Tailwind
        sudo apt install npm
        from ~/, run the below:
        npm install --save-dev tailwindcss @tailwindcss/cli @tailwindcss/typography

links:
    Hugo Blox: https://github.com/HugoBlox/kit
    Blocks: https://github.com/HugoBlox/kit/tree/main/modules/blox/blox
    Academic CV: https://hugoblox.com/templates/details/academic-cv/
    Academic CV: https://github.com/HugoBlox/kit/tree/main/templates/academic-cv

clone base website:
git clone https://github.com/salecharohit/testsite.com website_content
cd website_content
git submodule update --init --recursive

download Hugo extended version from here:
https://github.com/gohugoio/hugo/releases
extract it and run the "hugo server" command from the website_content directory

see base website:
sudo apt install hugo
./view.sh
keep script running, hugo updates the website automatically

push it to an own repository on GitHUB
set up netlify from GitHub by giving permission to the website

open directory in VS code
important subdirectories: config, content

create a new post:
hugo new --kind post post/<post_name> hugo new --kind post post/test_post

import publications
python3 -mvenv ~/venv/website
. ~/venv/website/bin/activate
pip3 install academic
cp <publications.bib> website_content/
academic import publications.bib content/publication/ --compact
